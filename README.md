
# Mini SOC Threat Detection

## About
A beginner-friendly Python cybersecurity project that simulates a Security Operations Center (SOC) alert system by analyzing failed login attempts.

## Features
- Failed login attempt input
- Input validation
- HIGH, MEDIUM, and LOW severity classification
- Brute-force attack alert simulation
- Alert logging in alerts.txt
- Alert summary

## Technologies Used
- Python
- Git
- GitHub
- Visual Studio Code

## How to Run
1. Clone the repository.
2. Open the project folder.
3. Run the following command:

   ```bash
   python main.py

## Disclaimer
This project is a beginner-level simulation. It does not monitor real system logs or detect actual attacks.
